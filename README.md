# Turkish Payroll Calculator 2026: human-designed vs LLM-generated tests

CMPE 411 (AI-Driven Software Testing and Quality Assurance) term project, İstanbul Bilgi University, Fall 2026.

A small web application computes the monthly gross-to-net salary for 2026: SGK and unemployment premiums with the SGK ceiling, cumulative income tax brackets, the minimum wage tax exemption and stamp tax, with raises and bonuses entered as rules. The tests are the main product. Tests designed by a person with classic techniques are compared with tests generated by an LLM, using coverage, mutation testing and planted defects.

![tests](https://github.com/emrs6/bordro-test/actions/workflows/tests.yml/badge.svg)

## Run it (≈ 5 minutes)

Requires Python 3.11.

```bash
git clone https://github.com/emrs6/bordro-test.git
cd bordro-test
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
pytest
```

All tests (unit, API and end-to-end in a real browser) run with the single `pytest` command.

To use the web page:

```bash
uvicorn api:app
```

Then open http://127.0.0.1:8000. Example: January gross `50.000`, Hesapla → January net **40.207,53 TL**.

| `tests/llm/` | **LLM group:** generated tests that passed the review |
| `tests/gelistirici/` | Developer checks against the specification's control values (not part of the comparison) |
| `tests/api/`, `tests/e2e/` | API tests (FastAPI TestClient) and end-to-end tests (Playwright) (not part of the comparison) |
| `ai/`, `deney/` | LLM prompts and raw outputs, review log, planted-defect versions, measurement scripts and results |
| `docs/anlatim/` | Module-by-module explanations (Turkish) |

## Test levels and techniques

- **Levels:** unit (pytest), API (FastAPI TestClient), end-to-end (pytest-playwright, Chromium).
- **Design techniques:** boundary value analysis, equivalence partitioning, decision table, state transition (tax brackets during the year).
- **AI element (option A):** LLM-generated tests from the written requirements, reviewed against the official parameters and compared with the human tests by coverage, mutation score (mutmut) and planted defects.

## Scope

Private sector, standard employee, calendar year 2026. Out of scope: carrying SGK excess to later months, disability deduction, retired employees, incentives.
